# R7RS-small conformance suite (vendored)

An external R7RS-small test suite, run as a gate by `test/r7rs-suite-tests.sh` from
`run-all-tests.sh`. It answers "what does the standard require that Emit does not do?" with a
number that moves, rather than with a measurement someone has to remember to repeat.

| File | Role |
|---|---|
| `r7rs-tests.scm` | The suite, **verbatim** from chibi-scheme. Do not edit. |
| `LICENSE.chibi-scheme` | Its license (BSD 3-clause), carried beside it because the file itself is unmodified. |
| `r7rs-tests.sha256` | Ties the suite to the generated manifest. `shasum -a 256 -c` verifies it. |
| `harness.scm` | A `(chibi test)` substitute, in the subset Emit accepts. |
| `forms.tsv` | Generated by `tools/r7rs-manifest.ss`: every top-level form, its section and extent. |
| `exclusions.tsv` | Hand-maintained: every form Emit cannot run, with a reason. |

## Provenance

- Upstream: `https://github.com/ashinn/chibi-scheme`, `tests/r7rs-tests.scm`
- Vendored from `master` on **2026-08-11**
- sha256 `9b10cac782ef9c52c4cb0a3a489f01415b1262785d7eb14c70fa88ab859cf950`
- 2516 lines, 1035 top-level forms

Upstream's own header notes the suite "covers all procedures and syntax in the small language
except `delete-file`" and assumes full Unicode, the full numeric tower, and all standard libraries.
Emit provides none of those three in full, which is why the exclusion manifest exists.

## The suite is verbatim, and that is a rule

Do not edit `r7rs-tests.scm` — not to quote a vector literal, not to widen an expected float, not
to delete a form Emit cannot compile. Its whole value is that it was written without knowledge of
Emit's limitations; a local edit silently converts a gap into a pass. All local accommodation goes
in `harness.scm` (how results are compared) or `exclusions.tsv` (what is skipped, and why).

This is also why no license header was added to it: a header would make the file differ from
upstream and break `r7rs-tests.sha256`. See `LICENSE.chibi-scheme`.

Refreshing the suite means: replace the file, regenerate `forms.tsv`
(`chez --script tools/r7rs-manifest.ss`), update `r7rs-tests.sha256`, and re-check
`exclusions.tsv` for entries whose forms no longer exist.

## Why a manifest instead of just running the file

Emit compiles a whole program before running any of it, so **one unsupported form aborts every
test in the file** — unlike an interpreter, where it costs one test. The runner therefore assembles
each section from the forms `forms.tsv` names, skipping those `exclusions.tsv` excludes.

`exclusions.tsv` is checked in **both** directions, which is what keeps it honest:

- a form that is not excluded but no longer runs is a **regression** — the suite fails
- a form that is excluded but now **passes** is a **stale exclusion** — the suite also fails

So closing a conformance gap announces itself: the run names the forms that started passing, and
the fixing commit deletes their entries. An exclusion is a claim, and the suite checks the claim.

## Reason tags in `exclusions.tsv`

| Tag | Meaning |
|---|---|
| `deliberate:<ref>` | Emit will never support this; `<ref>` is the issue or spec that decided so |
| `issue-NN` | A filed defect |
| `unimplemented` | A known gap with no issue yet |
| `blocked-by:<key>` | Excluded only because the form it depends on is excluded |

`blocked-by` is separated out on purpose: a reference to a helper whose `define` was excluded is
not an independent gap, and counting it as one overstates the inventory.

## Current baseline

Measured on 2026-08-11, after the change that introduced this suite:

```
assertions: 779 passed, 0 failed;  forms: 791 run, 389 excluded
22 section/check groups passed, 0 failed          (about 2 minutes)
```

The 389 exclusions, by reason class:

| Reason | Forms | What it is |
|---|---|---|
| `unimplemented` | 231 | `(scheme char)`, `(scheme lazy)`, binary ports, derived syntax, `(scheme eval)`, ... |
| `deliberate:#27` | 87 | exact rationals, bignums, complex numbers -- permanently absent |
| `issue-74` | 16 | reader: named characters, hex escapes, string escapes, inf/nan case |
| `blocked-by:*` | 15 | a helper's defining form is excluded -- not independent gaps |
| `deliberate:not-R7RS-small` | 8 | `1s2`/`1f2`-style exponent markers, which R7RS-small does not have |
| `issue-82` | 7 | mutable pairs |
| `issue-85` | 6 | `read-error?`/`file-error?` need an error-object kind |
| `issue-84` | 5 | crashes with a signal (no tag check on accessors) |
| `issue-75` | 4 | datum labels, `#!fold-case` |
| `issue-78`, `issue-86` | 3 each | `apply` on a non-list; flonum print convention |
| `issue-81` | 2 | `case` with `=>` |
| `issue-77`, `issue-80` | 1 each | exact/inexact comparison; `_` as a syntax-rules literal |

For contrast, the same suite against the compiler immediately before the change ran 651 forms with
529 excluded, for 635 passing assertions. Sections 6.8 Vectors and 6.9 Bytevectors moved most, from
3 of 43 and 6 of 39 forms running to 43 of 43 and 28 of 39.

(An earlier, throwaway measurement is often quoted as 506 passing. That one covered only 999 forms
-- its form splitter dropped the file's tail -- so it is not comparable to these numbers.)
