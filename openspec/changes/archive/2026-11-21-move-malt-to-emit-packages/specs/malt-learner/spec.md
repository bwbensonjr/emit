### Requirement: The learner facade is an ordinary explicit library

**Reason**: `(malt learner)` moves out of Emit into the `bwbensonjr/emit-packages` collection, which owns its specification, tests, and releases from this change on. Emit no longer ships or specifies the library.

**Migration**: Clone `bwbensonjr/emit-packages` and add its `lib/` directory as a library root, for example `EMIT_LIBRARY_PATH=/path/to/emit-packages/lib`. Imports of `(malt learner)` then resolve unchanged.
